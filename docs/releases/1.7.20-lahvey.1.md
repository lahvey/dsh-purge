# 1.7.20-lahvey.1

## 这一版做了什么

把上游 `kingcharleslzy-ai/dsh-purge` 的 **v1.7.20** 同步进 `lahvey/dsh-purge`（社区版），再把本仓库自己的增量重新贴回合并结果上。上一次同步停在 v1.6.97，中间跨了 1.6.98 → 1.7.20 二十多个发行。

## 上游带来的改动（节选）

- 拒绝重试：`attempt=1→2→3` 三臂（fiction / assistant-prefill seed / decompose），并区分 `partial_refused`（先给内容后拒）与 `empty_after_retry`（重试后几乎没内容），两者都不再算成功。
- 权限补丁（#6 #7 #8 #9 #10 #13 #14 #15 #16 #35 #51 #59 #60 #62）改为默认开启并收成组开关；上下文管理收成第二个组开关，默认关闭。
- 状态页重建：主数字按“条”计，拆成已应用 / 待应用 / 未启用 / 本端不适用四态，新增补丁组开关与状态过滤条，窄屏重新排版。
- 诊断计数统一：逐条诊断取代旧的分组摘要，补丁 71 改为按文件证据判定，补丁 90 保持未就绪。
- 文档拆分：`AGENTS.md` 下游拆出 maintenance-archive / troubleshooting / compatibility / maintenance-inspector-frame-budget。

## 本仓库保留的增量

- 评测台：`lib/redteam/eval-scorer.js`、`redteam_eval` 工具、内置题库（`presets/redteam/eval-bank-*.jsonl`）与对应回归测试。
- 规则预设：`lib/rules.js` 的结构化规则骨架与 `presets/rules/structured-rules-skeleton.md`。
- 面板版本提示只比主干 `X.Y.Z`，忽略 `-lahvey.N` 后缀。
- `-lahvey.N` 版本工作流：`master` 有新提交即自动推进 `package.json` 的版本，方便 profile 依赖看出装的是哪一版。

## 已知限制

- 本版不改宿主补丁表结构与提示词层级；原有补丁选择、提示词与规则在升级后继续有效。
- 固定版本 TGZ 指向本仓库 tag `v1.7.20-lahvey.1`；本仓库不带自动发行流水线，TGZ 由本机 `npm pack` 产出。
- Windows / macOS 宿主的真机验收与模拟测试分开报告，本版只在 macOS 上跑了功能与打包回归，不宣称其他平台已验收。
- 升级后需要重启 DSH 一次，面板与补丁状态才按新版本重新读取。
